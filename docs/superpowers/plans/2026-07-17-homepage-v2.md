# EduNex Homepage V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a high-end, accessible public homepage at `/homepage-v2` without changing the existing homepage or its visual system.

**Architecture:** Create a self-contained `HomepageV2` page with local data arrays and focused presentational subcomponents in one file, paired with a dedicated stylesheet so its visual system cannot leak into the existing claymorphic UI. Add a public React Router route in `App.tsx`; authenticated workspace access continues to use the existing `/dashboard` route.

**Tech Stack:** React 19, TypeScript, React Router 7, Tailwind CSS 4, Framer Motion 12, Lucide React, Vite 7.

## Global Constraints

- Keep `src/pages/LandingPage.tsx` and its route at `/` unchanged.
- Add `/homepage-v2` as a public route, preserving all protected routes.
- Use the Campus Command direction: deep eucalyptus/near-black, neutral white, one restrained lime signal; no blue/purple gradients, neon, glow bloom, glassmorphism, decorative grids, claymorphism, or repeated feature-card grids.
- Use only factual or explicitly illustrative content; do not invent customer logos, testimonials, school names, or product metrics.
- Meet WCAG 2.2 AA baseline: semantic landmarks, contrast, keyboard focus, touch targets, and reduced-motion behavior.
- Build with the existing dependency set; do not add packages.

---

## File Structure

- `src/pages/HomepageV2.tsx` — public route page, semantic content structure, local data, accessible navigation, and Framer Motion entrance behavior.
- `src/pages/HomepageV2.css` — isolated `homepage-v2` selectors, responsive rules, focus treatment, motion fallback, and product-scene styling.
- `src/App.tsx` — imports `HomepageV2` and exposes it at `/homepage-v2`.

- [ ] **Step 5: Author scoped, accessible CSS**

Build `HomepageV2.css` around a `.homepage-v2` token scope. Include mobile and tablet breakpoints that recompose sections rather than merely shrinking them.

```css

  --hx-surface: #ffffff;
  --hx-lime: #b8f28b;

  color: var(--hx-ink);

  outline: 3px solid var(--hx-lime);
```
