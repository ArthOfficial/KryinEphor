Kryin Ephor - The OS for Modern Schools

Kryin Ephor is a multi-tenant school management SaaS platform for modern school administration.
It brings school operations into one secure operating system for administrators, teachers,
students, parents, accountants, receptionists, and platform owners.

Core product facts from the project README and product notes:
- Multi-tenant school management platform.
- Tenant isolation through school_id and row-level security.
- 54-table Supabase/Postgres data model.
- 211 RLS policies referenced by the project documentation.
- Seven-role RBAC: super admin, admin, teacher, student, parent, accountant, receptionist.
- Super admin dashboard with schools, students, teachers, subscriptions, revenue, system health.
- School database and tenant administration.
- User management and role-aware permissions.
- Class management, attendance, homework, examinations, grading, timetable scheduling.
- Finance and billing: fee structures, invoices, transactions, salary, payroll, subscriptions.
- Communication layer: notifications, events, messages, threads.
- Security layer: audit logs, system logs, login attempts, sessions.
- Roadmap: parent portal, student self-service, teacher class management, online classes,
  SMS/push notifications, mobile responsive redesign, advanced analytics, exports.
